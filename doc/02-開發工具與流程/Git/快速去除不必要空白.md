利用 git apply 去處理掉不必要的空白

```shell
git apply --whitespace=fix <patch file>
```

完整方案

```shell
# 使用 git diff 取得 patch, 注意要加 --binary 以便支援處理 binary 檔案
git diff --binary -p > temp.patch

# 若有 untracked file, 使用 git add 先加入
git diff --cached --binary -p > temp.patch

# 清理 workspace
git stash
git stash -u  # 若有 untracked file

# apply patch
git apply --whitespace=fix temp.patch

# 確認沒問題後，清理 stash
git stash drop
```

若要處理 ^M 這麼換行符號錯誤問題
可以對 patch 檔案處理在 apply

```shell
# 使用 dos2unix 工具處理
dos2unix temp.patch

# 使用 sed 刪除 \r 符號 (linux \n, windows \r\n)
sed -i 's/\r$//' temp.patch
```

### 最後的方案

**要處理的檔案先 `git add`**

```shell
#!/bin/bash

patch_file=$(mktemp)
git diff --cached --binary -p > $patch_file
git reset
sed -i 's/\r$//' $patch_file
git apply --cached --whitespace=fix $patch_file
rm $patch_file
```
