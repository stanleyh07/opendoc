```bash
while IFS= read -r line; do
	if [[ $line =~ Port[[:space:]]+([0-9]+).*Class=([^,]+) ]]; then
		port="${BASH_REMATCH[1]}"
		class="${BASH_REMATCH[2]}"
	.....
done < <(lsusb -t)
```
這是一種在 Bash shell 中使用的進程替換（process substitution）語法。讓我詳細解釋一下：

**<(lsusb -t):**
這部分是進程替換。
它會執行 lsusb -t 命令。
將該命令的輸出作為一個臨時文件提供。

**< :**
這是輸入重定向操作符。
它將右邊的內容作為輸入。
組合起來，< <(lsusb -t) 的作用是：

執行 lsusb -t 命令
將該命令的輸出作為一個臨時文件
將這個臨時文件作為輸入提供給 while 循環的 read 命令
這種方法的優點包括：

避免了創建實際的臨時文件，更加高效。
允許在 while 循環中直接讀取命令輸出，而不需要使用管道（pipe）。
保持了 while 循環在當前 shell 環境中執行，而不是在子 shell 中。
在這個腳本中，它被用來逐行讀取並處理 lsusb -t 命令的輸出，以解析 USB 設備信息。這種方式使得腳本能夠更有效地處理 USB 設備的數據。

後續內容
```bash
	if [[ $line =~ Port[[:space:]]+([0-9]+).*Class=([^,]+) ]]; then
		port="${BASH_REMATCH[1]}"
		class="${BASH_REMATCH[2]}"
```

這段代碼用於從 lsusb -t 命令的輸出中提取 USB 端口號和設備類別信息。讓我詳細解釋：

```
if [[ $line =~ Port[[:space:]]+([0-9]+).*Class=([^,]+) ]]; then
```

這是一個條件判斷，使用正則表達式匹配 $line 中的特定模式。
**=~**
這是正則表達式匹配操作符，用於檢查左邊的字符串是否匹配右邊的正則表達式模式。

```bash
Port[[:space:]]+([0-9]+) 
```

 匹配 "Port" 後跟一個或多個空白字符，然後是一個或多個數字（捕獲組1）。
.* 匹配任意字符。

```bash
Class=([^,]+) 
```

匹配 "Class=" 後跟一個或多個非逗號字符（捕獲組2）。


```bash
port="${BASH_REMATCH[1]}"
class="${BASH_REMATCH[2]}"
```

如果匹配成功，將第一個捕獲組（端口號）賦值給 port 變量。
將第二個捕獲組（設備類別）賦值給 class 變量。
