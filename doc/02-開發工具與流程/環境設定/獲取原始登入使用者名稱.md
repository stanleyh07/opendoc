# 在 Ubuntu 下獲取原始登入使用者名稱

當你在 Ubuntu 上使用 `sudo` 切換到 root，直接執行 `whoami` 或查看 `$USER` 都只能拿到 `root`，無法反映最初登入的使用者名稱。下面列出四種常見且可靠的做法。

## 方法一：使用 SUDO_USER 環境變數

- `sudo` 命令會在環境中設定 `SUDO_USER` 為發起 `sudo` 的原始使用者名稱。
- 如果當前使用者不是透過 `sudo` 提權，則該變數為空。

示例腳本：

```bash
if [ -n "$SUDO_USER" ]; then
  real_user="$SUDO_USER"
else
  real_user="$USER"
fi

echo "當前登入使用者：$real_user"
```

## 方法二：使用 logname 命令

- `logname` 會回傳本次終端登入的使用者名稱，不受 `sudo` 影響。
- 相容性好，幾乎所有 Linux 發行版都支援。

```bash
real_user=$(logname)
echo "當前登入使用者：$real_user"
```

## 方法三：使用 who am i

- `who am i`（等價於 `who -m`）顯示當前終端的原始登入資訊，其中第一個欄位即為使用者名稱。
- 如果終端會話是從其他使用者切換過來，仍然會回傳最初登入的使用者。

```bash
real_user=$(who am i | awk '{print $1}')
echo "當前登入使用者：$real_user"
```

## 方法四：透過 TTY 檔案所有者

- 當前終端對應的裝置檔案（如 `/dev/pts/0`）歸屬最初登入的使用者。
- 使用 `stat -c %U $(tty)` 可讀取該裝置檔案的所有者。

```bash
real_user=$(stat -c %U "$(tty)")
echo "當前登入使用者：$real_user"
```

---

以上方法各有優缺點：

- **SUDO_USER**：最直觀，在腳本中推薦首選。
- **logname / who am i**：不依賴 Shell 環境變數，終端工具友好。
- **stat**：依賴檔案系統資訊，適合不信任環境變數或需要更高可靠性的場景。

---

更多延伸：

- 在 Python 中可用 `os.getenv("SUDO_USER") or os.getlogin()` 獲取相同資訊。
- 在 C 語言中呼叫 `getlogin()` 函式，結合 `getenv("SUDO_USER")`，也能實現類似功能。
