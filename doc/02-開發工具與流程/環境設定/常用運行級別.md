下面是關於 Unix 和 Linux 系統中不同運行級別的詳細介紹：

### 運行級別 0

`init 0`

- **描述**: 將系統關機。    
- **用途**: 當你需要安全地關閉系統時使用。    

### 運行級別 1

`init 1`

- **描述**: 單用戶模式（單人模式），僅允許根用戶登入。    
- **用途**: 用於系統維護和故障排除，允許對系統進行維護而不影響其他用戶。    

### 運行級別 2

`init 2`

- **描述**: 多用戶模式，但不支持網絡（某些系統中）。    
- **用途**: 允許多用戶登入，但無網絡支持。    

### 運行級別 3

`init 3`

- **描述**: 完整的多用戶模式，包括網絡支持，但沒有圖形化用戶界面（GUI）。    
- **用途**: 適用於伺服器環境或者需要節省資源的情況。    

### 運行級別 4

`init 4`

- **描述**: 通常未使用，可以為特殊用途進行自定義。    
- **用途**: 根據具體需求設置特殊運行級別。    

### 運行級別 5

`init 5`

- **描述**: 完整的多用戶模式，包括網絡支持和圖形化用戶界面（GUI）。    
- **用途**: 適合大多數桌面環境的用戶。    

### 運行級別 6

`init 6`

- **描述**: 重啟系統。    
- **用途**: 當需要重新啟動系統時使用。    

這些運行級別的具體功能和用途可能會根據不同的 Unix 或 Linux 發行版而有所不同，以上是大多數發行版的常見設置。

### 範例

```bash
sudo init 3     # stop the desktop
# log your user back into the console (Ctrl+Alt+F1, F2, ect)
sudo init 5     # restart the desktop
```
