在 **Bash** 裡，`${}` 是一個非常強大的字串處理工具，通常用來做 **參數展開 (parameter expansion)**。它不只是單純取變數值，還能進行字串操作。以下是幾個常見用法：

---

## 🔑 常見字串處理方法

### 1. 取代字串

```bash
name="hello_world"
echo ${name/_/-}       # 將第一個 "_" 替換成 "-"
echo ${name//_/ -}     # 將所有 "_" 替換成 " -"
```

- `${var/pattern/replacement}`：只替換第一個符合的字串
- `${var//pattern/replacement}`：替換所有符合的字串

---

### 2. 取得字串長度

```bash
text="abcdef"
echo ${#text}   # 輸出 6
```

---

### 3. 字串截取 (substring)

```bash
text="abcdef"
echo ${text:2}      # 從索引 2 開始 → "cdef"
echo ${text:2:3}    # 從索引 2 開始取 3 個字 → "cde"
```

---

### 4. 移除字串前後匹配

```bash
file="backup.tar.gz"
echo ${file%.gz}      # 移除結尾的 ".gz" → "backup.tar"
echo ${file%%.tar.gz} # 移除最長匹配的 ".tar.gz" → "backup"
echo ${file%%.tar*}   # 移除最長匹配的 ".tar" 及後面所有字串 → "backup"

echo ${file#*.}     # 移除最短匹配的前綴直到 "." → "tar.gz"
echo ${file##*.}    # 移除最長匹配的前綴直到 "." → "gz"
```

---

### 5. 預設值與替代

```bash
unset var
echo ${var:-"default"}   # 如果 var 未定義或空字串，輸出 "default"，這裡輸出 "default"

var=""
echo ${var-"default"}   # 如果 var 未定義，輸出 "default"，這裡輸出 ""
```


---

# 📖 Bash `${}` 字串處理對照表

|功能|語法|範例|結果|
|---|---|---|---|
|**變數展開**|`${var}`|`name="Stanley"; echo ${name}`|`Stanley`|
|**字串長度**|`${#var}`|`text="abcdef"; echo ${#text}`|`6`|
|**字串截取**|`${var:pos}` / `${var:pos:len}`|`text="abcdef"; echo ${text:2:3}`|`cde`|
|**替換 (單次)**|`${var/pat/repl}`|`s="a_b_c"; echo ${s/_/-}`|`a-b_c`|
|**替換 (全部)**|`${var//pat/repl}`|`s="a_b_c"; echo ${s//_/ -}`|`a - b - c`|
|**移除後綴 (最短匹配)**|`${var%pat}`|`f="backup.tar.gz"; echo ${f%.gz}`|`backup.tar`|
|**移除後綴 (最長匹配)**|`${var%%pat}`|`f="backup.tar.gz"; echo ${f%%.tar.gz}`|`backup`|
|**移除前綴 (最短匹配)**|`${var#pat}`|`f="backup.tar.gz"; echo ${f#*.}`|`tar.gz`|
|**移除前綴 (最長匹配)**|`${var##pat}`|`f="backup.tar.gz"; echo ${f##*.}`|`gz`|
|**預設值 (未定義或空值)**|`${var:-default}`|`unset v; echo ${v:-"N/A"}`|`N/A`|
|**僅在未定義時賦值**|`${var:=default}`|`unset v; echo ${v:="N/A"}`|`N/A` 並設定 `v="N/A"`|
|**錯誤提示**|`${var:?msg}`|`unset v; echo ${v:?"missing var"}`|錯誤：`missing var`|
|**替代值 (僅在已定義時)**|`${var:+alt}`|`v="ok"; echo ${v:+"yes"}`|`yes`|

---

💡 **使用場景**

- **檔名處理**：快速去掉副檔名或路徑
- **字串清理**：替換或刪除特定符號
- **參數安全**：提供預設值避免未定義錯誤
