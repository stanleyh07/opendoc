---

# 📝 Bash 參數展開對照表

| 語法                | 行為                                                                   | 範例                               | 結果                 |
| ----------------- | -------------------------------------------------------------------- | -------------------------------- | ------------------ |
| `${VAR:-default}` | 如果 **未設定或為空字串** → 用 `default`；否則用原值                                  | `FOO="" ; echo ${FOO:-bar}`      | `bar`              |
| `${VAR-default}`  | 如果 **未設定** → 用 `default`；如果已設定（即使是空字串） → 用原值                         | `FOO="" ; echo ${FOO-bar}`       | `""` (空字串)         |
| `${VAR:=default}` | 如果 **未設定或為空字串** → 用 `default`，並且 **把 VAR 設成 default**                | `unset FOO ; echo ${FOO:=bar}`   | `bar` 且 `FOO=bar`  |
| `${VAR=default}`  | 如果 **未設定** → 用 `default`，並且 **把 VAR 設成 default**；如果已設定（即使是空字串） → 用原值 | `FOO="" ; echo ${FOO=bar}`       | `""`               |
| `${VAR:?message}` | 如果 **未設定或為空字串** → 顯示錯誤訊息並退出                                          | `unset FOO ; echo ${FOO:?error}` | `bash: FOO: error` |
| `${VAR?message}`  | 如果 **未設定** → 顯示錯誤訊息並退出；如果已設定（即使是空字串） → 用原值                           | `FOO="" ; echo ${FOO?error}`     | `""`               |
| `${VAR:+alt}`     | 如果 **已設定**（不管值是什麼） → 用 `alt`；如果未設定 → 空字串                             | `FOO="hi" ; echo ${FOO:+bar}`    | `bar`              |

---

### 🔑 小結

- `:-` → **未設定或空字串** → fallback
- `-` → **未設定** → fallback
- `:=` / `=` → 同時會 **賦值**
- `:?` → **錯誤檢查**
- `:+` → **條件替換**
