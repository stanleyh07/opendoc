
# 📝 常見命名方式對照表

|命名方式|範例|特點|常見用途|
|---|---|---|---|
|**PascalCase (UpperCamelCase)**|`RingId`, `UserProfile`, `CustomerOrder`|每個單字首字母大寫，第一個字也大寫|類別名稱、型別名稱、命名空間|
|**camelCase (lowerCamelCase)**|`ringId`, `userProfile`, `customerOrder`|第一個字母小寫，後續單字首字母大寫|變數名稱、函式名稱、物件屬性|
|**snake_case**|`ring_id`, `user_profile`, `customer_order`|單字間用底線分隔，全小寫|資料庫欄位、Python 變數、環境變數|
|**kebab-case**|`ring-id`, `user-profile`, `customer-order`|單字間用連字號分隔，全小寫|URL、檔案名稱、前端 CSS class|
|**SCREAMING_SNAKE_CASE**|`RING_ID`, `USER_PROFILE`, `CUSTOMER_ORDER`|全大寫，單字間用底線分隔|常數、環境變數|

---

📌 **快速記憶法**

- **PascalCase** → 大駝峰，類別/型別用
- **camelCase** → 小駝峰，變數/函式用
- **snake_case** → 底線蛇，資料庫/腳本用
- **kebab-case** → 連字號串，URL/CSS用
- **SCREAMING_SNAKE_CASE** → 全大寫蛇，常數用

# 🌐 跨語言命名規範建議

|語言/環境|類別/型別|變數/函式|常數|特殊用途|
|---|---|---|---|---|
|**Java / C#**|PascalCase → `UserProfile`|camelCase → `userProfile`|SCREAMING_SNAKE_CASE → `MAX_VALUE`|Package/Namespace → 全小寫 `com.example.project`|
|**Python**|PascalCase → `UserProfile`|snake_case → `user_profile`|SCREAMING_SNAKE_CASE → `MAX_VALUE`|模組/檔案 → `user_profile.py`|
|**C++**|PascalCase → `UserProfile`|camelCase 或 snake_case → `userProfile` / `user_profile`|SCREAMING_SNAKE_CASE → `MAX_VALUE`|命名空間 → 小寫 `namespace project`|
|**JavaScript / TypeScript**|PascalCase → `UserProfile`|camelCase → `userProfile`|SCREAMING_SNAKE_CASE → `MAX_VALUE`|檔案/路徑 → kebab-case → `user-profile.js`|
|**Go (Golang)**|PascalCase (公開) → `UserProfile`|camelCase (私有) → `userProfile`|SCREAMING_SNAKE_CASE → `MAX_VALUE`|Package → 全小寫 `userprofile`|
|**Rust**|PascalCase → `UserProfile`|snake_case → `user_profile`|SCREAMING_SNAKE_CASE → `MAX_VALUE`|Crate/Module → snake_case `user_profile`|
|**Android build system (Make/Soong)**|PascalCase → `DeviceTreeConfig`|snake_case → `device_tree_config`|SCREAMING_SNAKE_CASE → `BOARD_VENDOR`|環境變數 → SCREAMING_SNAKE_CASE|

---

## 📌 建議策略

1. **類別/型別 → PascalCase**  
    保持一致性，跨語言都容易辨識。
    
2. **變數/函式 → camelCase 或 snake_case**    
    - Java/C# → camelCase
    - Python/Rust → snake_case
    - Go → 視公開/私有決定大小寫
    
3. **常數/環境變數 → SCREAMING_SNAKE_CASE**  
    這是最通用的規範，跨語言幾乎一致。
    
4. **檔案/模組 → snake_case 或 kebab-case**    
    - Python/Rust → snake_case
    - JS/TS → kebab-case
    - Android → snake_case
