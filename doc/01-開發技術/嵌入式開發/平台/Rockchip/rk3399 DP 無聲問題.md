2. 雖然可以撥放聲音，但缺乏自動偵測 DP 的功能，需要修改 rk3399 driver 
   添加偵測相關的 call back 函數等內容
```
/* 
   kernel/drivers/gpu/drm/rockchip/cdn-dp-core.c  
*/
 
static void handle_plugged_change(struct cdn_dp_device *dp, bool plugged)
{
       if (dp->plugged_cb)
               dp->plugged_cb(dp->codec_dev, plugged);
}

static int dp_audio_hook_plugged_cb(struct device *dev, void *data,
                                      hdmi_codec_plugged_cb fn,
                                      struct device *codec_dev)
{
       struct cdn_dp_device *dp = dev_get_drvdata(dev);

       dp->plugged_cb = fn;
       dp->codec_dev = codec_dev;
       handle_plugged_change(dp, dp->connected);
       return 0;
}

static const struct hdmi_codec_ops audio_codec_ops = {
        .hw_params = cdn_dp_audio_hw_params,
        .audio_shutdown = cdn_dp_audio_shutdown,
        .mute_stream = cdn_dp_audio_mute_stream,
        .get_eld = cdn_dp_audio_get_eld,
        .no_capture_mute = 1,
        .hook_plugged_cb = dp_audio_hook_plugged_cb  // 添加
};

```

   detect 函數中添加處理 DP event 機制
```
   static void cdn_dp_pd_event_work(struct work_struct *work) 
   {
	   ....
	   handle_plugged_change(dp, dp->connected);
   }
```
   
3. 修正 ubuntu 聲卡相關設定
   使用 ubuntu 的聲卡設定去播放聲音會有問題，但使用 aplay 卻不會
   根據 rockchip 回復，跟聲音 buffer 的大小，有兩種方式
   **第一種方法**
        
```
修改 /etc/pulse/daemon.conf ， 
   default-fragments = 8
   default-fragment-size-msec = 5 # 42/8～=5  
```
以上設定可以參考[[02-開發工具與流程/環境設定/音訊/PulseAudio 音訊設定檔 (daemon.conf)]]

```
修改/etc/pulse/default.pa 
load-module module-udev-detect tsched=0 #行尾添加 tsched=0

```
此設定可以參考[[02-開發工具與流程/環境設定/音訊/PulseAudio 音訊設定檔 (default.pa)]]

**第二種方法**
修改 dma buffer 大小
```
/*
	kernel/drivers/dma/pl330.c
*/

#define MCODE_BUFF_PER_REQ     512  //從 256 改成 512
```
