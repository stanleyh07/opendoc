
使用 chroot 進入虛擬機的機制是這樣的：

- 當您在命令行中執行一個不同架構的程序時，系統會調用 binfmts 模塊來識別它的類型，並調用之前註冊的解釋器來啟動它。例如，如果您執行一個 ARM 的程序，系統會調用 /usr/bin/qemu-arm-static 來翻譯並執行它。
- 當您使用 chroot 命令時，您會將一個目錄指定為新的根目錄，並在該目錄下執行一個 shell 或其他程序。這樣，您就可以模擬一個與原系統隔離的文件系統環境。
- 如果您在 chroot 環境中執行一個不同架構的程序，系統依然會從 /usr/bin 中尋找對應的解釋器，但這時的 /usr/bin 是指新根目錄下的 /usr/bin，而不是原系統的 /usr/bin。因此，您需要將 qemu-aarch64-static 複製到新根目錄下的 /usr/bin 中，才能正常執行 ARM 的程序。
- 這樣，您就可以使用 chroot 和 qemu 來進入一個虛擬的 ARM 環境，並在其中運行和調試您提取出的文件系統中的程序。

**這就是如何在 host  X86 上，去建立 embedded ARM64 的 rootfs 機制原理。**
