# 知識庫寫入技能

當用戶要求將對話內容整理到知識庫時，請依以下流程執行：

## 流程

### 1. 回顧對話
檢視對話內容，提取關鍵資訊與知識點，判斷哪些內容值得納入知識庫。

### 2. 分類歸檔
- 先搜尋 `doc/` 全目錄確認是否已有相關內容
- 依 [[doc/00-知識庫核心/目錄結構與分類標準]] 決定分類位置
- 若已有相關內容，應整合至既有文件，不得刪減原有內容

### 3. 執行寫入
- **新文件**：遵循 Obsidian 格式（YAML frontmatter、wikilinks、Callout 等）
- **既有文件**：以新增章節的方式補充，保留完整脈絡
- 更新 frontmatter 中的 `modified` 日期
- 檔案命名依分類規則（見 [[doc/00-知識庫核心/目錄結構與分類標準#檔案命名建議]]）

### 4. 關聯維護
- 使用 `[[wikilink]]` 建立文件間的連結關係
- 若新增分類目錄，須更新 [[doc/00-知識庫核心/目錄結構與分類標準]]

## 注意事項
- 所有文件必須使用繁體中文撰寫
- 專有名詞可保留原文對照
- 禁止刪減既有文件的任何內容
